VegasCraft ships this copy of Minecraft's launcher setup so New Vegas can start Minecraft by itself.
VegasCraft doesn't include Minecraft: Prism Launcher downloads it after you sign in with a
Microsoft account that owns Minecraft: Java Edition.

The bundle uses Minecraft 26.3, Fabric Loader 0.19.5 and Java 25, downloaded by Prism.
New Vegas multiplayer integration is experimental and has not been validated.
Native Pip-Boy icons and map images are generated locally from the installed New Vegas
game files; extracted game assets and account data are not included in this bundle.
